# Content Review Guide (Admin)

1. Dashboard → Content承認待ち
2. Queue で REVIEWING を開く
3. 本文 preview / Claims / Reviews / Policy を確認
4. 最新 Version であること（`isLatest`）を確認
5. Approve / Reject / Request changes 等を実行

## 禁止事項

- 既存 Version 本文の直接編集
- 古い Version の承認
- FAILED Review / UNSUPPORTED Claim の承認

本文修正が必要な場合は新 ContentVersion を作成する（既存 revision / regeneration フロー）。
